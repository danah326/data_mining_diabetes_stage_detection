## About the Project

This project explores the use of data mining techniques to detect and 

classify diabetes stages based on patient health records. The pipeline 

covers the full data mining workflow — from raw data preprocessing through 

to classification, clustering, and model evaluation.

## Features

- Data preprocessing and cleaning on a ~1,000-record diabetes dataset

- Feature discretization for categorical binning

- Decision tree classification using both Gini and Entropy criteria

- K-Means clustering to identify patient groupings

- Side-by-side evaluation and comparison of all applied techniques
